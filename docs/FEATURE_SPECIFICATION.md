# 책결 기능 명세표

기준일: 2026-08-28  
대상: 개인용 VIP 배포본(Android 우선), Go API, PostgreSQL, 운영자 웹  
운영 주소: `https://34-64-97-191.sslip.io`  
운영자 센터: `https://34-64-97-191.sslip.io/admin`

이 문서는 책결의 **현재 동작 계약**을 한눈에 확인하기 위한 기준 문서다. 제품 아이디어가 아니라 저장소의 화면, API, DB 저장 및 현재 개인 서버 배포 상태를 대조해 작성했다.

## 1. 상태 판정 기준

| 상태 | 의미 | 이 구분이 틀렸을 때 나타나는 현상 |
|---|---|---|
| ✅ 운영 중 | 화면·API·DB 저장이 연결되어 있고 현재 개인 서버에서 사용할 수 있음 | 기능을 눌렀을 때 404/5xx, 저장 후 재조회 시 데이터 유실 |
| 🧪 코드 완료 | 구현과 정적/통합 검증은 끝났지만 외부 자격 증명 또는 실기기 검증이 남음 | 화면은 동작해도 푸시·딥링크 등 외부 효과가 발생하지 않음 |
| ⚠️ 개발 전용 | 개발 편의를 위해 열어 둔 기능이며 공개 운영 기준에는 부적합 | 제3자가 운영자 화면이나 개발 인증 경로에 접근할 수 있음 |
| ⏳ 후속 개발 | 요구사항만 확정했거나 로드맵에 있으며 현재는 사용할 수 없음 | 화면 또는 API 자체가 없거나 일부 흐름에서 중단됨 |

`✅ 운영 중`은 모든 상용 출시 조건이 끝났다는 뜻이 아니다. 현재 개인 서버에서 기능 흐름이 이어진다는 뜻이며, 스토어 출시·외부 인증·운영 보안은 별도로 판정한다.

## 2. 전체 기능 명세

### 2.1 계정과 인증

| ID | 기능 | 사용자 동작·결과 | 화면/API·저장 | 상태 | 제약·예외 |

| AUTH-001 | 최초 계정 생성 | 닉네임·이메일·10자 이상 비밀번호로 첫 계정을 생성하고 로그인 상태가 됨 | `sign-in` · `POST /v1/auth/register` · PostgreSQL | ✅ 운영 중 | 개인 모드에서는 첫 계정 생성 후 추가 가입이 닫힘 |
| AUTH-002 | 이메일 로그인 | 등록한 이메일과 비밀번호로 30일 세션을 발급받음 | `sign-in` · `POST /v1/auth/login` | ✅ 운영 중 | 이메일 인증과 비밀번호 찾기는 아직 없음 |
| AUTH-003 | 세션 유지·로그아웃 | 앱 재실행 시 세션을 복원하고 로그아웃 시 서버 세션을 폐기함 | SecureStore · `POST /v1/auth/logout` | ✅ 운영 중 | Android에서는 Keystore 기반 저장소 사용 |
| AUTH-004 | 접근 보호 | 인증되지 않았거나 정지·차단된 계정의 보호 API 접근을 거절함 | Go 인증 미들웨어 | ✅ 운영 중 | `ALLOW_DEV_AUTH` 우회는 로컬 개발에만 허용해야 함 |
| AUTH-005 | 소셜 로그인 | Kakao·Google·Apple 계정으로 가입·로그인 | 미구현 UI, JWT/JWKS 서버 경계만 존재 | ⏳ 후속 개발 | Supabase 프로젝트와 각 공급자 설정이 선행되어야 함 |
| AUTH-006 | 비밀번호 복구 | 이메일로 본인 확인 후 새 비밀번호 설정 | 미구현 | ⏳ 후속 개발 | 공개 베타 전 메일 발송·토큰 만료 정책 필요 |

### 2.2 도서 탐색과 등록

| ID | 기능 | 사용자 동작·결과 | 화면/API·저장 | 상태 | 제약·예외 |

| BOOK-002 | ISBN 조회 | ISBN으로 판본 한 건을 조회해 책장 등록으로 연결함 | `GET /v1/catalog/books/{isbn}` | ✅ 운영 중 | 잘못된 ISBN 또는 미등록 도서는 찾지 못할 수 있음 |

| BOOK-005 | 전체 페이지 수 보강 | Kakao 검색 결과의 ISBN을 Google Books와 대조하여 전체 쪽수를 표시함 | Kakao → Google Books `pageCount` 보강 | ✅ 운영 중 | 정확한 ISBN 판본에 값이 있을 때만 표시하며 없으면 생략됨 |
| BOOK-006 | 페이지 수 수동 보완 | 자동 쪽수가 없거나 판본과 다르면 사용자가 전체 분량을 직접 지정함 | 책 등록 흐름 · `pageCount`/진척 기준 | ✅ 운영 중 | 검색 등록 UI는 1~100,000쪽을 허용하며 판본별 차이는 사용자가 확인 |

### 2.3 내 책장과 독서 회차

| ID | 기능 | 사용자 동작·결과 | 화면/API·저장 | 상태 | 제약·예외 |
|---|---|---|---|---|---|
| LIB-001 | 책장 목록 | 등록한 모든 독서 회차를 상태별로 확인함 | `library` · `GET /v1/reading-runs` | ✅ 운영 중 | 서버 실패 시 마지막 로컬 캐시를 표시할 수 있음 |
| LIB-002 | 독서 상태 | 읽고 싶음, 읽는 중, 잠시 멈춤, 완독, 중단으로 변경함 | `book/[runID]` · `PATCH /v1/reading-runs/{id}` | ✅ 운영 중 | 내부 값은 `want_to_read`, `reading`, `paused`, `finished`, `dnf` |
| LIB-003 | 책 형식 | 종이책·전자책은 쪽/퍼센트, 오디오북은 재생 시간으로 기록함 | 등록·상세 화면 · `progressBasis` | ✅ 운영 중 | 자동 분량이 없으면 퍼센트 기준으로 기록 가능 |
| LIB-004 | 재독 회차 | 같은 판본을 다시 읽을 때 이전 기록을 보존한 새 회차를 생성함 | 책 등록 · `runNumber` | ✅ 운영 중 | 동일 판본의 읽는 중/일시정지 회차 중복 생성은 제한됨 |
| LIB-005 | 공유 기본값 | 책마다 공개 범위, 진척 정밀도, 자동 공유 여부를 설정함 | `book/[runID]` · 독서 회차 설정 | ✅ 운영 중 | 그룹 공개는 사용자가 해당 그룹 구성원이어야 함 |
| LIB-006 | 책장 검색·정렬 | 제목·저자로 검색하고 상태별로 거른 뒤 최근 기록, 제목, 진척순으로 정렬함 | `library` · 로컬 목록 탐색 | ✅ 운영 중 | 검색과 정렬은 서버 재요청 없이 현재 동기화된 책장에 적용됨 |
| LIB-007 | 독서 회차 제거 | 책 상세에서 확인 후 회차와 진척·공유 기록을 책장에서 제거함 | `book/[runID]` · `DELETE /v1/reading-runs/{id}` | ✅ 운영 중 | 되돌릴 수 없으며 본인이 소유한 회차만 제거 가능 |
| LIB-008 | 태그·컬렉션 | 책을 사용자 정의 주제와 묶음으로 분류하고 복합 필터로 탐색함 | 미구현 | ⏳ 후속 개발 | 책장 50권 이상 사용성 검증 후 설계 |

### 2.4 독서 기록

| READ-002 | 한 줄 메모 | 진척 기록과 함께 짧은 생각을 남김 | 기록 화면 · `progress_entries.note` | ✅ 운영 중 | 공개 범위에 따라 피드 메모 노출이 달라짐 |

| READ-004 | 과거 기록 | 책별 진척·메모·시간 기록을 시간순으로 확인함 | `book/[runID]` · `GET .../entries` | ✅ 운영 중 | 기록 수정·삭제 UI는 현재 제공하지 않음 |
| READ-005 | 감소 보정 | 앞선 값보다 작은 진척을 기록하면 정정 기록으로 저장하고 이미 생성된 잘못된 마일스톤을 취소함 | 멱등 처리·직렬화 트랜잭션 | ✅ 운영 중 | 동일 `clientOperationId` 재전송은 중복 생성하지 않음 |
| READ-006 | 오프라인 저장 | 네트워크가 없으면 작업을 로컬 대기열에 두고 연결 후 재전송함 | SQLite 큐·실패 작업 재시도 UI | ✅ 운영 중 | 웹은 SQLite 대신 `localStorage`를 사용함 |
| READ-007 | OCR 인용문·사진 메모 | 책 문장을 촬영해 인용문으로 저장함 | 미구현 | ⏳ 후속 개발 | 카메라 권한, 저작권, 민감정보 정책 필요 |

### 2.6 그룹, 공개 범위와 스포일러

| ID | 기능 | 사용자 동작·결과 | 화면/API·저장 | 상태 | 제약·예외 |

| GROUP-003 | 그룹 한정 공유 | 선택한 그룹 구성원에게만 독서 이벤트를 노출함 | 독서 회차 `visibility=group` | ✅ 운영 중 | 그룹 ID 누락·비구성원 지정은 거절됨 |

| PRIV-003 | 스포일러 잠금 | 댓글을 항상 공개, 해당 위치 이후, 완독 후 중 하나로 설정함 | 댓글 API · 독자 진척 비교 | ✅ 운영 중 | 조건 미충족자는 댓글 내용 대신 잠금 상태를 봄 |

## 4. 데이터·정책 명세

### 4.1 독서 상태와 진척

| 항목 | 허용 값 | 동작 규칙 |
|---|---|---|
| 독서 상태 | 읽고 싶음(`want_to_read`), 읽는 중(`reading`), 잠시 멈춤(`paused`), 완독(`finished`), 중단(`dnf`) | 상태 변경 시 시작·완료 시간이 갱신되며 진척 기록에 따라 읽는 중/완독 상태가 보정될 수 있음 |
| 진척 기준 | 쪽(`pages`), 퍼센트(`percent`), 오디오 초(`audio_seconds`) | 원본 값과 전체 분량으로 0~100% 정규화 값을 계산 |
| 자동 피드 | 시작, 25%, 50%, 75%, 완독 | 새로 넘은 가장 높은 대표 마일스톤만 생성하고 감소 정정 시 잘못된 이벤트를 무효화 |
| 멱등성 | UUID `clientOperationId` | 같은 작업이 재전송되어도 진척 기록은 한 번만 생성 |

### 4.3 페이지 수 결정 규칙

| 순서 | 원천 | 규칙 | 실패 시 |
|---:|---|---|---|
| 1 | Kakao Books | 제목·저자·표지·출판사·ISBN 등 기본 판본 정보를 가져옴 | 로컬 카탈로그 또는 빈 결과 |
| 2 | Google Books | 검색 상위 결과의 정확한 ISBN을 조회해 양수 `pageCount`만 보강 | 페이지 수 필드를 생략하고 검색 결과는 유지 |
| 3 | 사용자 입력 | 자동 값이 없거나 실제 판본과 다르면 직접 전체 분량 지정 | 퍼센트 기준 기록 선택 가능 |

Google Books 보강은 검색 결과 상위 10건을 대상으로 최대 5개 동시 요청, 전체 약 5초 제한, 프로세스 메모리 양수 캐시를 사용한다. 따라서 API 장애나 할당량 초과가 발생해도 도서 검색 자체는 실패시키지 않고 페이지 수만 없는 상태로 반환한다.

## 9. 변경 관리 규칙

- 화면, API 경로, DB 스키마, 공개 범위 또는 외부 의존성이 바뀌면 같은 변경에서 이 문서를 갱신한다.
- `✅ 운영 중`으로 올리기 전에 최소 한 번의 정상 흐름과 대표 실패 흐름을 확인한다.
- 외부 자격 증명이 없는 상태에서 UI만 존재하면 `🧪 코드 완료` 이상으로 표시하지 않는다.
- 현재 배포와 GitHub 기준선이 다르면 배포 커밋과 미반영 사유를 릴리스 기록에 남긴다.
- 삭제·제재·공개 범위처럼 되돌리기 어렵거나 개인정보에 영향을 주는 기능은 회귀 테스트 없이 상태를 올리지 않는다.
