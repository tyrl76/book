기준일: 2026-09-02

## 4. 확인된 제약

- Kakao 도서 검색 결과의 ISBN을 Google Books와 대조해 전체 페이지 수를 가능한 경우에만 보강한다. Google에 정확한 판본 값이 없거나 판본별 분량이 다르면 사용자가 쪽수·퍼센트·오디오 시간을 선택한다.
- 사용자 웹앱은 `/app/`에서 Android와 같은 서버 데이터와 주요 화면을 제공한다. 푸시는 웹에서 비활성화되고, Expo SQLite의 OPFS 다중 탭 제약을 피하기 위해 웹 캐시는 `localStorage` 어댑터를 사용한다.
- `public`은 현재 책결 사용자 전체 피드 공개를 뜻한다. 외부 웹 공유 링크는 후속 기능이다.
- 개인 모드는 최초 소유자 등록 뒤 공개 가입이 닫히고 운영 센터에서 테스트 계정을 추가할 수 있지만 이메일 인증·비밀번호 복구가 없다. Tailscale 사설망을 벗어난 공개 서비스에는 그대로 사용하지 않는다.
- 운영자 콘솔의 `X-Admin-ID`는 감사 표시용 값이다. 개인별 신원을 보증하려면 운영 배포 앞단에 IAP/SSO를 둬야 한다.
- 운영 센터의 실시간 로그는 API 프로세스 메모리에서만 최근 1,000건을 유지한다. Worker 로그와 재시작 전 이력은 파일 또는 외부 로그 수집기에서 확인한다.
- `ALLOW_DEV_AUTH=true`와 `X-User-ID`는 로컬 개발 전용이다.
- 앱과 Docker 초기화 과정은 샘플 사용자·책·피드를 생성하지 않는다.

## 5. 검증 결과

- `go test ./...` 통과
- `pnpm typecheck` 통과
- `pnpm lint` 통과
- `pnpm exec expo export --platform web`로 29개 정적 라우트 생성 성공
- 운영 로그인 화면에서 잘못된 자격 증명 입력 시 지속형 오류 배너, 정확한 안내 문구, 재시도 버튼 노출 확인
- 기존 서명 지문을 유지한 Android `versionCode 17` APK와 동일 소스 웹 릴리스 배포, 다운로드·웹·API 상태 HTTP 200 확인
- `/app/`, `/app/sign-in`, `/app/library`, `/app/people`, `/app/friend/[userID]`, 해시 정적 자산, 친구·그룹 초대 웹 fallback HTTPS 200 검증
- 390×844 모바일 브라우저에서 로그인·홈·기록·검색·친구 화면의 가로 넘침과 콘솔 오류 없이 렌더링 검증
- 인증 복원 전 보호 경로를 판단하지 않도록 하여 로그인 상태의 웹 탭·상세 경로가 새로고침 뒤에도 유지되는지 검증
- 웹에서 계정 영구 삭제 공통 확인창의 취소·확정 UI와 실제 삭제 후 로그인 화면 복귀를 검증하고 일회성 QA 계정 잔존 0건 확인
- 독서 회차 제거 API 단위 테스트와 소유권·연관 기록 정리 PostgreSQL 통합 테스트 추가
- 책장 검색·상태 필터·3종 정렬, 검색 실패 재시도, 검색어를 유지한 직접 등록 흐름 검증
- 독서 타이머 앱 재실행 복원·일시정지·초기화와 24시간 안전 상한 검증
- 임시 개인 계정으로 최초 가입 닫힘 → 로그아웃 토큰 폐기(401) → 재로그인 → PostgreSQL 상태 조회 → 계정 삭제 후 가입 재개 통합 검증
- 그룹 소유자/구성원/외부인 임시 계정으로 권한 통합 테스트 통과
- 그룹 구성원 피드 노출 1건, 외부인 노출 0건 확인
- 25% 마일스톤, 리액션, 위치 기반 스포일러 잠금, 독서 중 상태 확인
- 알림 전달 큐가 `pending` 상태와 내부 딥링크를 생성하는 것 확인
- 신고 생성 → 운영자 숨김 → 피드 제외 → 복원 → 피드 재노출과 감사 로그 확인
- 운영 콘솔을 데스크톱과 390×844에서 확인하고 브라우저 오류 0건 확인
- Expo 동적 설정에서 iOS Associated Domains와 Android `autoVerify` intent filter 생성 확인
- 브라우저 1280×720과 390×844에서 가로 오버플로 0, 라이트/다크 선택, 핵심 화면 확인
- 실제 두 계정으로 인증·양방향 친구 조회·친구 피드 노출·응원 추가/표시/취소 원복 흐름 통과, 친구는 있으나 책이 없는 계정에 첫 책 CTA·상태별 빈 화면·피드 필터를 적용
- 개인 서버에서 Google Books 키 직접 호출 200, `googleBooksPageCount=true` 확인
- 한 글자 검색어 `눈`으로 운영 카탈로그 5건 반환, 빈 검색어는 400 `invalid_query`로 차단 확인
- 검색어 `한`의 1·2페이지에서 각각 20권 반환, 페이지 간 중복 ISBN 0건, 웹 번들의 연관 검색·무한 스크롤 코드 포함 확인
