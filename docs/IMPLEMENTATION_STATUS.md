기준일: 2026-08-28

이 문서는 현재 저장소에서 실제로 실행되는 기능, 외부 계정이나 인프라 연결이 필요한 기능, 아직 제품 로드맵에만 있는 기능을 구분한다.

## 4. 확인된 제약

- Kakao 도서 검색 결과의 ISBN을 Google Books와 대조해 전체 페이지 수를 가능한 경우에만 보강한다. Google에 정확한 판본 값이 없거나 판본별 분량이 다르면 사용자가 쪽수·퍼센트·오디오 시간을 선택한다.
- 웹은 개발·QA 보조 대상이며 첫 출시 우선순위는 iOS/Android다. 푸시는 웹에서 비활성화되고, Expo SQLite의 OPFS 다중 탭 제약을 피하기 위해 웹 캐시는 `localStorage` 어댑터를 사용한다.
- `public`은 현재 책결 사용자 전체 피드 공개를 뜻한다. 외부 웹 공유 링크는 후속 기능이다.
- 개인 모드는 한 계정만 가입할 수 있고 이메일 인증·비밀번호 복구가 없다. Tailscale 사설망을 벗어난 공개 서비스에는 그대로 사용하지 않는다.
- 운영자 콘솔의 `X-Admin-ID`는 감사 표시용 값이다. 개인별 신원을 보증하려면 운영 배포 앞단에 IAP/SSO를 둬야 한다.
- 운영 센터의 실시간 로그는 API 프로세스 메모리에서만 최근 1,000건을 유지한다. Worker 로그와 재시작 전 이력은 파일 또는 외부 로그 수집기에서 확인한다.
- `ALLOW_DEV_AUTH=true`와 `X-User-ID`는 로컬 개발 전용이다.
- 앱과 Docker 초기화 과정은 샘플 사용자·책·피드를 생성하지 않는다.

## 5. 검증 결과

- `go test ./...` 통과
- `pnpm typecheck` 통과
- `pnpm lint` 통과
- `pnpm exec expo export --platform web`로 26개 정적 라우트 생성 성공
- 임시 개인 계정으로 최초 가입 닫힘 → 로그아웃 토큰 폐기(401) → 재로그인 → PostgreSQL 상태 조회 → 계정 삭제 후 가입 재개 통합 검증
- 그룹 소유자/구성원/외부인 임시 계정으로 권한 통합 테스트 통과
- 그룹 구성원 피드 노출 1건, 외부인 노출 0건 확인
- 25% 마일스톤, 리액션, 위치 기반 스포일러 잠금, 독서 중 상태 확인
- 알림 전달 큐가 `pending` 상태와 내부 딥링크를 생성하는 것 확인
- 신고 생성 → 운영자 숨김 → 피드 제외 → 복원 → 피드 재노출과 감사 로그 확인
- 운영 콘솔을 데스크톱과 390×844에서 확인하고 브라우저 오류 0건 확인
- Expo 동적 설정에서 iOS Associated Domains와 Android `autoVerify` intent filter 생성 확인
- 브라우저 1280×720과 390×844에서 가로 오버플로 0, 라이트/다크 선택, 핵심 화면 확인
- 개인 서버에서 Google Books 키 직접 호출 200, `googleBooksPageCount=true` 확인
- 제목 `채식주의자` 검색 10건 중 7건, `한강` 검색 10건 중 4건에서 전체 페이지 수 표시 확인
- ISBN `9788936434595` 정확 조회에서 `pageCount` 반환 및 운영자 도서 검색 화면 표시 확인
